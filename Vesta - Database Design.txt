Vesta - Database Design

Users

| Field    | Type    | Description     |
| -------- | ------- | --------------- |
| user_id  | INT     | Primary key     |
| username | VARCHAR | User's username |
| email    | VARCHAR | User's email    |
| password | VARCHAR | User's password |

Clothing_Items

| Field       | Type    | Description                                       |
| ----------- | ------- | ------------------------------------------------- |
| clothing_id | INT     | Primary key                                       |
| user_id     | INT     | Owner of the clothing item                        |
| name        | VARCHAR | Name of the clothing item                         |
| category    | VARCHAR | Clothing category, such as shirt, pants, or shoes |
| color       | VARCHAR | Main color of the clothing item                   |
| style       | VARCHAR | Style of the clothing item                        |
| image_url   | VARCHAR | URL of the clothing image                         |

Outfits

| Field      | Type     | Description                                         |
| ---------- | -------- | --------------------------------------------------- |
| outfit_id  | INT      | Primary key                                         |
| user_id    | INT      | User who owns the outfit                            |
| occasion   | VARCHAR  | Occasion, such as university, casual, or work       |
| style      | VARCHAR  | Outfit style, such as simple, streetwear, or formal |
| weather    | VARCHAR  | Weather condition the outfit is suitable for        |
| created_at | DATETIME | Date and time the outfit was created                |

Outfit_Items

| Field       | Type | Description                    |
| ----------- | ---- | ------------------------------ |
| outfit_id   | INT  | Reference to the outfit        |
| clothing_id | INT  | Reference to the clothing item |

Favorite_Outfits

| Field       | Type | Description             |
| ----------- | ---- | ----------------------- |
| favorite_id | INT  | Primary key             |
| user_id     | INT  | Reference to the user   |
| outfit_id   | INT  | Reference to the outfit |

Outfit_History

| Field      | Type | Description                   |
| ---------- | ---- | ----------------------------- |
| history_id | INT  | Primary key                   |
| user_id    | INT  | Reference to the user         |
| outfit_id  | INT  | Reference to the outfit       |
| worn_date  | DATE | Date when the outfit was worn |
